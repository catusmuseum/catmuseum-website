# 貓太太的珍物館 — 官方網站

Catus's Doll Museum 官方網站靜態版本。

## 頁面結構

```
index.html       — 首頁（活動資訊、關於我們）
vendor.html      — 攤商報名
event.html       — Vol.7 台中場 2026.9.25 活動詳情
reviews.html     — 活動記錄／回顧
contact.html     — 聯絡方式
css/style.css    — 共用樣式
images/          — 圖片素材（需手動放入）
```

## 使用方式

直接開啟 `index.html` 即可瀏覽。

## 發布方式

### 方案 A：GitHub Pages（免費，推薦）

1. 在 GitHub 建立新 repository
2. 將全部檔案上傳
3. 啟用 GitHub Pages（Settings → Pages → 選 main branch）
4. 網址即為 `https://你的帳號.github.io/倉庫名/`

### 方案 B：本機使用

直接從瀏覽器開啟 `index.html` 即可。

### 方案 C：自訂網域

可使用 GitHub Pages 自訂網域功能，或上傳到任何支援靜態網站的 hosting。

## 更新方式

告訴我 → 我修改 HTML → 重新上傳即可。
